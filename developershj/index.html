Quick Start

4단계로 API를 시작하세요

신청서 작성부터 첫 API 호출까지 빠르게 시작할 수 있습니다.

1

신청서 작성

담당자 이름과 이메일을 입력하고, 필요한 경우 서비스 정보를 추가합니다.

2

약관 동의

API Key 발급에 필요한 필수 약관에 동의합니다.

3

API Key 즉시 발급

API Key가 즉시 발급되고 신청 정보가 JSON으로 저장됩니다.

4

API 호출

X-API-Key 헤더에 Key를 넣고 API를 호출합니다.

curl 
# 도서 검색 API 호출
curl -X GET "https://api.yes24.com/v1/goods/itemList?query=클린코드&pageSize=10" \
  -H "X-API-Key: yk_live_YOUR_API_KEY"
