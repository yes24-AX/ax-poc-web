GET

/v1/books

키워드, ISBN, 저자, 출판사 등 다양한 조건으로 도서를 검색합니다.

최종 업데이트: 2026년 6월 · Books API v2.1

개요

도서 목록을 검색하고 결과를 반환합니다. 키워드 기반 풀텍스트 검색 외에도 ISBN, 저자명, 출판사, 카테고리 코드로 필터링할 수 있습니다. 결과는 관련도 순, 출판일 순, 판매량 순으로 정렬 가능합니다.

Endpoint

GET https://api.yes24.com/v1/books

인증

모든 요청에 Bearer Token이 필요합니다. Access Token 발급 방법을 먼저 확인하세요.

Request Header 
Authorization: Bearer {access_token}
Content-Type: application/json

Rate Limit

플랜분당 요청응답 헤더
Free100X-RateLimit-Limit: 100
Standard500X-RateLimit-Limit: 500

Request Headers

헤더타입필수설명
Authorization string Required

Bearer {access_token} 형식
Accept-Language string Optional

응답 언어 설정. 기본값: ko

Query Parameters

파라미터타입필수설명
query string Required

검색 키워드. 제목, 저자, 출판사에서 풀텍스트 검색.
isbn string Optional

ISBN-10 또는 ISBN-13으로 특정 도서 조회.

예: 9788996044246
category string Optional

카테고리 코드. /v1/codes/categories에서 조회.

예: IT001
sort string Optional

정렬 기준. relevance | pubdate | sales

기본값: relevance
page integer Optional

페이지 번호 (1 이상)

기본값: 1
size integer Optional

페이지당 결과 수 (1~100)

기본값: 20

Request Example

curl -X GET "https://api.yes24.com/v1/books?query=클린코드&size=10&sort=sales" \
  -H "Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9..." \
  -H "Accept-Language: ko"
const response = await fetch(
  'https://api.yes24.com/v1/books?query=클린코드&size=10&sort=sales',
  {
    headers: {
      'Authorization': `Bearer ${accessToken}`,
      'Accept-Language': 'ko',
    },
  }
);
const data = await response.json();
console.log(data);
using System.Net.Http;
using System.Net.Http.Headers;

var client = new HttpClient();
client.DefaultRequestHeaders.Authorization =
    new AuthenticationHeaderValue("Bearer", accessToken);

var response = await client.GetAsync(
    "https://api.yes24.com/v1/books?query=클린코드&size=10&sort=sales");

var json = await response.Content.ReadAsStringAsync();
Console.WriteLine(json);
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
    .url("https://api.yes24.com/v1/books?query=클린코드&size=10&sort=sales")
    .addHeader("Authorization", "Bearer " + accessToken)
    .addHeader("Accept-Language", "ko")
    .build();

try (Response response = client.newCall(request).execute()) {
    System.out.println(response.body().string());
}

Error Codes

HTTP에러 코드설명
400BOOKS_001query 파라미터가 없거나 비어있음
400BOOKS_002size 값이 유효 범위(1~100)를 벗어남
401AUTH_001유효하지 않거나 만료된 Access Token
403AUTH_003해당 API에 대한 권한 없음
429RATE_001Rate Limit 초과. X-RateLimit-Reset 헤더 확인
500SERVER_001서버 내부 오류. 재시도 후 지속 시 지원팀 문의
