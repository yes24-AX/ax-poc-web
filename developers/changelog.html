API 변경 이력

주요 기능 추가·정책 변경·버그 수정 내역을 시간순으로 정리합니다. 큰 변경은 최소 30일 전 사전 공지합니다.

v1.4.0 MINOR 2026-05-20

리뷰 AI 요약 기능 추가

  • GET /v1/products/{id}/reviews 응답에 summary 파라미터 추가
  • 긍정·부정 키워드 클러스터링 결과 함께 제공
  • 자동완성 API의 응답 속도 평균 23% 개선 (P95 28ms)
v1.3.2 PATCH 2026-04-11

버그 수정 및 안정성 개선

  • 일부 ISBN13에서 발생하던 500 응답 케이스 수정
  • 한글 검색어가 5자 이상일 때 인코딩 누락되던 이슈 수정
v1.3.0 MINOR 2026-03-04

저자·출판사 API 일반 공개

  • GET /v1/authors/{id}, GET /v1/authors/{id}/books 정식 출시
  • 출판사 검색을 GET /v1/search의 field=publisher로 제공
v1.2.0 MAJOR 2026-02-01

애드온 (파트너 정산) 프로그램 출시

  • POST /v1/addon/affiliate-links 신규 엔드포인트 추가
  • 콘솔에 "정산" 탭 추가 — 실시간 매출·정산 내역 확인
  • 파트너 계약 절차를 온라인 신청으로 통합
v1.1.3 PATCH 2025-12-15

Rate Limit 헤더 표준화

  • 응답 헤더를 X-RateLimit-* 표준에 맞춰 정렬
  • 기존 X-Rate-Limit-* 헤더는 2026-06-01부터 제거 예정
v1.1.0 MINOR 2025-10-22

베스트셀러 / 신간 / 스테디 셀러 API 출시
