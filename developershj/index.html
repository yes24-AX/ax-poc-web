Quick Start

4단계로 API를 시작하세요

계정 생성부터 첫 API 호출까지 10분이면 충분합니다.

1

신청서 작성

서비스 정보와 담당자 이메일을 입력합니다.

2

약관 동의

이용약관 및 개인정보 처리에 동의합니다.

3

API Key 즉시 발급

신청 즉시 API Key가 발급됩니다.

4

API 호출

헤더에 Key를 넣고 API를 호출합니다.

curl 
# 도서 검색 API 호출
curl -X GET "https://api.yes24.com/v1/books?query=클린코드&size=10" \
  -H "X-API-Key: yk_live_YOUR_API_KEY"
