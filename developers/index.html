Why YES24 OpenAPI

믿을 수 있는 도서 데이터 인프라

국내 최대 도서 유통 데이터를 기반으로, 개발자가 바로 쓸 수 있는 안정적인 API를 제공합니다.

📚

풍부한 서지 데이터

ISBN 기반 정규화된 메타데이터, 표지 이미지, 목차, 저자 정보 등 풍부한 도서 데이터를 한 곳에서 제공합니다.

⚡

빠른 응답과 안정성

전 세계 CDN, Redis 캐시 레이어, 분산 인프라로 평균 82ms의 응답 시간을 보장합니다.

🔐

안전한 인증 체계

OAuth 2.0 호환 Bearer Token 방식, IP 화이트리스트, 호출 로그 추적까지. 보안을 신경 쓰지 않아도 됩니다.

📈

실시간 집계 데이터

일/주/월간 베스트셀러, 카테고리별 순위, 신간 알림 등 마케팅과 큐레이션에 바로 쓰는 집계 API.

🤝

애드온 수익 연계

파트너 사이트라면 추천 결과에 자동으로 제휴 링크를 삽입해 매출의 일정 비율을 정산받을 수 있습니다.

🧰

친절한 개발자 경험

OpenAPI 3.1 스키마, Postman 컬렉션, SDK 샘플(Node·Python·Java)을 함께 제공합니다.

API Catalog

지금 사용할 수 있는 API

도서 큐레이션·이커머스·콘텐츠 추천 등 다양한 시나리오에 맞춰진 6종의 API 묶음.

📖

상품 상세 API

ISBN 또는 상품번호로 도서·음반·DVD의 상세 메타데이터, 표지, 가격 정보를 조회합니다.

GET /v1/products/{id}
🔍

통합 검색 API

키워드, 저자, 출판사, 카테고리 등 다양한 조건으로 도서를 검색하고 페이지네이션할 수 있습니다.

GET /v1/search
🏆

베스트셀러 / 집계 API

일·주·월간 단위 베스트셀러, 카테고리별 순위, 신간/스테디 셀러 집계 데이터를 제공합니다.

GET /v1/rankings
🗂️

카테고리 / 분류 API

YES24 표준 카테고리 트리, KDC/DDC 매핑, 신간 카테고리 분류 체계를 받아옵니다.

GET /v1/categories
✍️

저자·출판사 API

저자 프로필, 출간 도서 목록, 출판사 정보 등 저자/출판사 중심 데이터를 다룹니다.

GET /v1/authors/{id}
💬

리뷰 / 평점 API

도서별 평균 평점, 최근 리뷰 요약, 회원 리뷰 통계 등 사회적 신호 데이터를 제공합니다.

GET /v1/products/{id}/reviews
Quickstart

4단계로 시작하는 YES24 OpenAPI

1️⃣

API Key 신청

이름·이메일·사용 목적만 입력하면 평균 1영업일 내 무료 발급. 애드온 연동 시 추가 정보 입력.

2️⃣

레퍼런스 학습

요청·응답 예제와 함께 제공되는 레퍼런스로 5분 안에 첫 호출 완료.

3️⃣

실서비스 연동

SDK 또는 cURL/HTTP 라이브러리로 자사 서비스에 연동하고 사용량을 콘솔에서 확인.

4️⃣

애드온으로 수익화

파트너 회원이라면 추천 결과에 제휴 링크 자동 삽입 → 매월 수익 정산.
