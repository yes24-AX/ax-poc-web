FAQ

YES24 Open API 이용 중 자주 묻는 질문입니다.

API Key는 어떻게 발급받나요? +

API Key 신청 페이지에서 담당자 정보, 서비스 정보, YES24 계정 정보를 입력하면 즉시 발급됩니다. 입력한 신청 정보와 발급 결과는 브라우저의 로컬 저장소에 JSON 형태로 저장됩니다.

API Key는 어디에 넣어야 하나요? +

발급받은 API Key는 모든 요청의 X-API-Key 헤더에 포함합니다. 별도의 Auth API나 토큰 발급 절차는 사용하지 않습니다.

로그인하지 않아도 API 문서를 볼 수 있나요? +

문서, API 카탈로그, 오류 코드, FAQ는 로그인 없이 확인할 수 있습니다. 내 애플리케이션과 발급된 Key 관리는 로그인 후 이용하는 개인 영역입니다.

내 애플리케이션은 어디에서 확인하나요? +

로그인 후 상단 오른쪽의 프로필 영역을 클릭하면 내 애플리케이션으로 이동합니다. 발급받은 API Key와 애플리케이션 상태를 이 화면에서 확인합니다.

API 테스트는 실제 API를 호출하나요? +

현재 API 테스트 화면은 실제 호출 화면과 동일한 입력 흐름을 제공하되, 응답은 각 API에 맞춘 예시 JSON으로 반환합니다. 실제 API 연동 전 요청 파라미터와 응답 구조를 확인하는 용도로 사용할 수 있습니다.

요청 파라미터는 어떻게 확인하나요? +

각 API 상세 문서의 Query Parameters 섹션에서 확인할 수 있습니다. API 테스트 화면의 Request Query Parameters도 선택한 API에 맞춰 동기화됩니다.

응답 형식은 모든 API가 동일한가요? +

공통 응답은 success, message, data, errorCode 구조를 사용합니다. 다만 data 안의 상세 필드는 API별로 다르며, 각 API 상세 문서의 Response Fields에서 확인할 수 있습니다.

페이지네이션은 어떻게 동작하나요? +

목록형 API는 보통 page와 pageSize 파라미터를 사용합니다. 기본 페이지는 1이며, 페이지 크기는 API 문서에 명시된 기본값과 최대값을 따릅니다.

오류 코드는 어디에서 확인하나요? +

공통 오류 코드는 문서 > 오류 코드에서 확인할 수 있습니다. API별로 자주 발생하는 오류는 각 API 상세 문서의 오류 코드 섹션에서도 안내합니다.

인증 오류가 발생하면 무엇을 확인해야 하나요? +

X-API-Key 헤더가 누락되지 않았는지, Key 값이 정확한지, 해당 API 사용 권한이 있는지, 애플리케이션 상태가 활성 상태인지 확인합니다.

Category API와 Goods API는 어떻게 다르나요? +

Category API는 카테고리 목록, 베스트셀러, 신상품처럼 카테고리 기준의 탐색 데이터를 제공합니다. Goods API는 상품 검색, 상품 상세, 목차, 작가 정보처럼 개별 상품 중심의 데이터를 제공합니다.

ISBN13과 ItemId 중 무엇을 사용해야 하나요? +

상품 상세, 상품 목차, 작가 기본 정보 조회에서는 searchType으로 ISBN13 또는 ItemId를 선택합니다. ISBN 기반 조회가 필요하면 ISBN13을, YES24 상품 번호를 알고 있으면 ItemId를 사용합니다.

API 사용량 제한이 있나요? +

운영 정책에 따라 요청량 제한이 적용될 수 있습니다. 제한을 초과하면 429 Too Many Requests가 반환될 수 있으며, 세부 기준은 운영 정책 확정 후 공지사항과 문서에 안내합니다.

상업적 서비스에 사용할 수 있나요? +

상업적 서비스 적용은 제공 범위, 호출량, 데이터 사용 방식에 따라 별도 검토가 필요할 수 있습니다. 서비스 출시 전 사용 목적과 데이터 노출 방식을 확인한 뒤 문의해 주세요.

문의는 어디로 하나요? +

오류나 사용 문의가 있으면 발생한 API, 요청 파라미터, 응답 전문, 발생 시각을 함께 정리해 담당 채널로 문의해 주세요. 오류 코드는 먼저 오류 코드 문서에서 확인할 수 있습니다.
