Error Codes

YES24 Open API에서 반환하는 오류 코드 목록입니다.

인증 오류 (AUTH)

코드HTTP메시지해결 방법
AUTH_001401Invalid or expired access tokenToken을 재발급받으세요. Access Token 유효기간은 1시간입니다.
AUTH_002401Missing Authorization headerAuthorization: Bearer {token} 헤더를 포함하세요.
AUTH_003403Insufficient permissions해당 API에 대한 권한을 신청하세요. My Applications > 권한 신청.
AUTH_004403Application is inactive앱이 비활성화 상태입니다. My Applications에서 앱 상태를 확인하세요.

요청 오류 (4xx)

코드HTTP메시지해결 방법
BOOKS_001400query parameter is requiredquery 파라미터를 포함하세요.
BOOKS_002400size must be between 1 and 100size 값을 1~100 범위로 조정하세요.
BOOKS_003404Book not found요청한 도서 ID가 존재하지 않습니다.
RATE_001429Rate limit exceeded요청 빈도를 줄이세요. X-RateLimit-Reset 헤더에서 초기화 시간 확인.
PARAM_001400Invalid parameter value파라미터 값 형식을 확인하세요.

서버 오류 (5xx)

코드HTTP메시지해결 방법
SERVER_001500Internal server error재시도 후 지속 시 지원팀에 문의하세요.
SERVER_002503Service temporarily unavailable점검 중입니다. 공지사항을 확인하세요.

오류 응답 본문의 error.docs 필드에는 해당 오류에 대한 문서 URL이 포함됩니다.

FAQ

API Key는 어디서 발급받나요? +

API Key 신청 페이지에서 서비스 정보와 약관 동의 후 즉시 발급받을 수 있습니다.

→ API Key 발급 가이드 상세 보기

Access Token 유효기간은 얼마나 되나요? +

Access Token의 유효기간은 1시간(3600초)입니다. 만료 후 Client Credentials로 재발급받으세요.

Rate Limit을 초과하면 어떻게 되나요? +

HTTP 429 Too Many Requests가 반환됩니다. 응답 헤더의 Retry-After 값만큼 대기 후 재시도하세요.

상업적 목적으로 사용할 수 있나요? +

네, 상업적 목적으로도 사용 가능합니다. 단, 이용 약관을 반드시 준수해야 합니다.

API 오류가 지속될 때 어떻게 문의하나요? +

support@developers.yes24.com으로 Client ID, 오류 발생 Endpoint, 오류 응답 전문, 발생 시각을 포함하여 문의해주세요.
