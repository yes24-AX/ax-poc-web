API Key 발급

YES24 Open API를 사용하려면 앱 등록과 API Key 발급이 필요합니다. 아래 절차를 따라 진행하세요.

사전 요건

  • YES24 계정이 있어야 합니다.
  • 사용하려는 API의 권한이 승인되어야 합니다.

발급 절차

  1. 신청 페이지 접속

    API Key 신청 페이지로 이동합니다.

  2. 서비스 정보 입력

    API를 사용할 서비스 정보를 입력합니다.

    • YES24 아이디 (선택) — 계정 연동 시 입력
    • 서비스명 및 서비스 URL
    • API 사용 목적
    • 담당자 이름 및 이메일
  3. 약관 동의

    이용약관, 개인정보 수집·이용, 개인정보 제3자 제공 동의(필수)에 체크합니다.

  4. API Key 즉시 발급

    신청 즉시 API Key가 화면에 표시됩니다. 입력한 이메일로도 발송됩니다.

    ⚠️

    API Key는 최초 발급 시에만 원문이 표시됩니다. 반드시 복사하여 안전한 곳에 보관하세요.

  5. 첫 API 호출

    발급받은 API Key를 헤더에 포함하여 API를 호출합니다.

    Shell 
    curl -X GET "https://api.yes24.com/v1/books?query=파이썬" \
  -H "X-API-Key: yk_live_YOUR_API_KEY"
🔒
보안 주의

Client Secret은 절대 클라이언트 사이드 코드(HTML, JavaScript)에 포함하지 마세요. 서버 사이드에서만 사용하세요.
