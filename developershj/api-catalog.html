API Catalog

YES24 Open API의 전체 카테고리입니다. 각 카테고리를 선택하면 상세 레퍼런스를 확인할 수 있습니다.

3개 Endpoint

Books API

도서 검색, 상세 정보 조회, 미리보기 기능을 제공합니다. ISBN, 저자, 출판사 등 다양한 조건으로 검색할 수 있습니다.

GET /v1/books — 도서 검색
GET /v1/books/{id} — 도서 상세
GET /v1/books/{id}/preview — 미리보기
4개 Endpoint

Products API

YES24에서 판매하는 상품의 가격, 재고, 할인 정보를 실시간으로 조회합니다. 장바구니 연동에 활용할 수 있습니다.

GET /v1/products — 상품 목록
GET /v1/products/{id} — 상품 상세
GET /v1/products/bestseller — 베스트셀러
GET /v1/products/new — 신상품
2개 Endpoint

Search API

YES24 통합 검색 기능을 API로 제공합니다. 자동완성, 연관 검색어, 오타 교정 기능이 포함됩니다.

GET /v1/search — 통합 검색
GET /v1/search/suggest — 자동완성
3개 Endpoint

Common Codes API

카테고리 분류 체계, 출판사 코드, 공통 코드 정보를 제공합니다. 필터 UI 구현에 활용하세요.

GET /v1/codes/categories — 카테고리
GET /v1/codes/publishers — 출판사 코드
GET /v1/codes/{type} — 공통 코드 조회
