API 카탈로그

YES24 Open API의 전체 카테고리입니다. 각 카테고리를 선택하면 상세 레퍼런스를 확인할 수 있습니다.

Category API

7개 Endpoint

Category API

YES24 카테고리 목록과 카테고리별 베스트셀러, 신상품, 주목할 신상품 목록을 조회합니다.

GET/v1/category/list카테고리 목록
GET/v1/category/bestsellerRealtime실시간 베스트셀러
GET/v1/category/bestseller종합 베스트셀러
GET/v1/category/bestsellerDeal특가 베스트셀러
GET/v1/category/bestsellerSteady스테디셀러
GET/v1/category/newproduct신상품
GET/v1/category/newproductAttention주목할 신상품

Goods API

4개 Endpoint

Goods API

검색어, 상품 번호, ISBN13을 기준으로 상품 목록, 상세 정보, 목차, 작가 기본 정보를 조회합니다.

GET/v1/goods/itemList상품 검색
GET/v1/goods/itemDetail상품 상세
GET/v1/goods/content상품 목차
GET/v1/goods/author작가 정보
