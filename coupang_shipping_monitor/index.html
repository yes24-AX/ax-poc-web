시안 메모 — 구현 조건과 판정 규칙
  • 데이터 원천: 쿠팡 발주서 목록 API(상품준비중). 출고예정일=estimatedShippingDate, 자사 상품번호=externalVendorSkuCode, 출고일=inTrasitDateTime.
  • 당일 출고 대상 = 출고예정일이 오늘이고 아직 상품준비중인 주문. 출고 지연 = 출고예정일이 지났는데 출고되지 않았거나, 지연된 뒤 출고된 주문.
  • 지연일수 = 기준일 − 주문시 출고예정일(달력일). 영업일로 셀지는 요청 부서 확인 필요.
  • 자사 주문번호·공개주문번호: 쿠팡 API에 없어 자사 매핑 원천이 정해져야 채웁니다.
  • 일자별 추이·AI의 반복 지연 판단: 집계 이력이 쌓여야 정확해집니다.
  • AI의 상품군: 쿠팡 카테고리(productCategoryLevel1/2) 기준입니다. 실제 값은 첫 수집 후 확인합니다.
  • 갱신 주기: 요청서의 1순위는 10~30분 간격입니다. 30분 수집이 가능한지는 영업관리시스템과 함께 쓰는 API 호출 한도를 확인한 뒤 정합니다.
  • 구매자·수취인 정보는 수집 즉시 버리고 저장하지 않습니다. 별도 알림(메일·메신저)은 두지 않습니다(요청서 기준).
