# V16 Experience

## Story

온라인서점 직원이 하나의 업무 질문을 암실의 빛 아래에 올린다. 상품, 콘텐츠, 판매, 주문이라는 서로 다른 데이터 표면을 모두 합쳐 정답을 만드는 것이 아니라, 초점을 바꾸며 지금 질문에 필요한 관점을 탐색한다.

## Interaction

- QUESTION: 빛을 드래그해 인화지 중앙의 초점점에 맞춘다.
- EXPOSURE: 상품 필름이 광축 안으로 이동한다.
- FOCUS: 초점 깊이에 따라 서로 다른 업무 필름이 선명해진다.
- CONTACT SHEET: 빛이 지면을 훑으며 여러 관점을 차례로 노출한다.
- DEVELOP: 인화지가 정면화되고 DataHub UI Shell로 전환된다.

각 장면은 도착 즉시 조작 가능한 상태가 된다. 스크롤은 사용하지 않으며, 우측 안내와 하단 동작 힌트에 따라 빛 선택, 필름 드래그, 다이얼 회전, 지면 스캔, 길게 누르기를 수행한다. 키보드 방향키와 Space도 대체 입력으로 사용할 수 있다. `PLAY THE JOURNEY`는 동일한 진행을 자동 재생한다.

## Meaning

현상된 결과는 원인, 정답 또는 추천 액션이 아니다. 사용자가 DataHub에서 어떤 데이터 관점을 살펴볼지 더 선명하게 인식하는 상태다.
