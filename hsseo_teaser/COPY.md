## 01 · 흩어짐 — 5.8초

가운데 큰 글자가 다섯 번 바뀝니다. 그 아래 줄에 그 영역의 프로그램이 나열됩니다.

```
[윗 라벨]     지금은

[큰 글자]  →  운영 시스템          [아래]  영업관리 · WMS · 매장에서
           →  전사 데이터 분석             MSTR · 매출 / 상품 / 고객 / 재고 / 경영지표에서
           →  마케팅 / 캠페인 분석         컴원 · 캠페인 / 발송 / 반응 / 전환에서
           →  사용자 행동 분석             클릭스트림 · GA4에서
           →  시스템 모니터링             배포 이력 · Elasticsearch · DB 로그에서
```

**카드 다섯 장** (각 카드 안의 글자)

| 카드 | 제목 | 영문 | 프로그램 — 설명 | 하단 |
|---|---|---|---|---|
| 01 | 운영 시스템 | OPERATIONS | 영업관리 — 주문·매출·정산<br>WMS — 입출고·재고<br>매장 — 매장 운영·재고 
| 02 | 전사 데이터 분석 | ENTERPRISE BI | MSTR — OLAP / BI<br>*(갈래)* 매출 · 상품 · 고객 · 재고 · 경영지표 분석 
| 03 | 마케팅 / 캠페인 분석 | CAMPAIGN | 컴원 — Comm.One<br>*(갈래)* 캠페인 · 발송 · 반응 · 전환 / 성과 
| 04 | 사용자 행동 분석 | BEHAVIOR | 클릭스트림 — 페이지·클릭·탐색 행동<br>GA4 — 유입·채널·전환 
| 05 | 시스템 모니터링 | MONITORING | 배포 이력 — 소스 배포 기록<br>Elasticsearch — 웹 서버 접근 로그<br>DB 로그 — 오류 로그

## 03 · 비용 — 6.4초

```
[작은 라벨]   판단 1건당 소요 · 샘플

[인용]        “어제 인문 매출이 왜 12% 빠졌지?”

[큰 수]       180 분
[그 아래]     질문 하나가 답이 되기까지

[구성비 아래] 이 중 160분(88%)이 여기저기서 뽑아 와 맞춰 보는 시간
```

**명세표**

| 항목 | 횟수 | 시간 |
|---|---:|---:|
| 시스템 접속 | 5회 | 10분 |
| 데이터 요청/조회 | 5회 | 30분 |
| 데이터 엑셀 내려받기·병합 | 5회 | 60분 |
| 기준 불일치 재확인 | 2회 | 60분 |
| 담당자 회신 대기 | 1건 | 20분 |
| **합계** | | **185분** |

(예시) 실제 업무 흐름을 설명하기 위한 예시이며, 측정된 평균값은 아닙니다.
```
[마무리 한 줄]  느린 건 사람이 아니라 **구조입니다.**
```

```

[출처 칩]     컴원 · 영업관리 · MSTR

[비교]        이전 · 찾고, 뽑고, 맞추고
              →
              지금 · 묻고, 바로 판단합니다.
```
