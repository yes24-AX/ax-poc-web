YES24 OpenAPI v1

YES24 Open API는 도서·음반·DVD 등 YES24가 보유한 상품 데이터에 RESTful 방식으로 접근할 수 있는 인터페이스입니다. 모든 요청은 HTTPS로만 수신하며, 응답은 기본 application/json; charset=utf-8 형식입니다.

Base URL

BASE https://api.yes24.com/v1

요청 형식

  • 모든 호출은 HTTPS 만 지원합니다.
  • 요청 헤더에 Authorization: Bearer {API_KEY} 를 반드시 포함합니다.
  • POST 요청의 Body는 JSON(application/json) 형식을 사용합니다.
  • 모든 응답은 UTF-8 인코딩의 JSON으로 반환됩니다.

인증

발급받은 API Key를 Authorization 헤더에 Bearer Token 방식으로 첨부합니다. 키 유출 방지를 위해 클라이언트(브라우저·앱)에 직접 노출하지 말고, 서버 사이드에서 호출하는 것을 권장합니다.

curl -X GET "https://api.yes24.com/v1/products/9788960778795" \
  -H "Authorization: Bearer yes24_live_xxxxxxxxxxxxxxxx" \
  -H "Accept: application/json"
const res = await fetch('https://api.yes24.com/v1/products/9788960778795', {
  headers: {
    'Authorization': 'Bearer yes24_live_xxxxxxxxxxxxxxxx',
    'Accept': 'application/json'
  }
});
const data = await res.json();
console.log(data);
import requests

resp = requests.get(
    'https://api.yes24.com/v1/products/9788960778795',
    headers={
        'Authorization': 'Bearer yes24_live_xxxxxxxxxxxxxxxx',
        'Accept': 'application/json'
    }
)
print(resp.json())

상품 상세 조회

ISBN13(13자리) 또는 YES24 상품번호(8자리)로 단일 상품의 상세 정보를 조회합니다.

GET /v1/products/{id}

Path Parameters

이름타입필수설명
idstring필수ISBN13 (13자리) 또는 YES24 상품번호 (8자리)

Query Parameters

이름타입필수설명
fieldsstring선택응답 필드 화이트리스트. 쉼표 구분. 예: title,author,price
includestring선택확장 필드 포함. toc(목차) · review_summary(리뷰요약)

요청 예제

curl -X GET "https://api.yes24.com/v1/products/9788960778795?include=toc" \
  -H "Authorization: Bearer yes24_live_xxxxxxxxxxxxxxxx"
const id = '9788960778795';
const res = await fetch(
  `https://api.yes24.com/v1/products/${id}?include=toc`,
  { headers: { 'Authorization': 'Bearer ' + API_KEY } }
);
const product = await res.json();
resp = requests.get(
    f'https://api.yes24.com/v1/products/{isbn}',
    params={'include': 'toc'},
    headers={'Authorization': f'Bearer {API_KEY}'}
)
product = resp.json()

상품 일괄 조회

최대 50건의 ISBN/상품번호를 한 번에 조회합니다. 추천·위시리스트 등 다건 호출 시나리오에 적합합니다.

POST /v1/products:batch

Body

이름타입필수설명
idsstring[]필수ISBN13 또는 상품번호 배열. 최대 50개
fieldsstring선택응답 필드 화이트리스트
 
curl -X POST "https://api.yes24.com/v1/products:batch" \
  -H "Authorization: Bearer yes24_live_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "ids": ["9788960778795", "9791162241813", "9788966262335"],
    "fields": "title,author,price,cover"
  }'

통합 검색

키워드 기반으로 도서를 검색합니다. 저자·출판사·카테고리 필터, 정렬, 페이지네이션을 지원합니다.

GET /v1/search

Query Parameters

이름타입필수설명
querystring필수검색어. 1자 이상 50자 이하
fieldstring선택검색 대상 필드. all(기본), title, author, publisher, isbn
categorystring선택카테고리 ID로 결과 한정
sortstring선택relevance(기본) · recent · sales · price_asc · price_desc
pagenumber선택페이지 번호. 기본 1
sizenumber선택페이지당 결과 수. 기본 20, 최대 50

자동완성

검색창에 입력 중인 키워드에 대한 추천 검색어 목록을 반환합니다. 키 입력 단위로 호출하는 것을 권장합니다.

GET /v1/search/autocomplete
이름타입필수설명
qstring필수입력 중인 키워드 (1자 이상)
limitnumber선택최대 결과 수. 기본 8, 최대 20

베스트셀러 / 집계

일·주·월간 단위 베스트셀러 순위, 카테고리별 순위 등 집계 데이터를 제공합니다. 결과는 1시간 단위로 캐싱됩니다.

GET /v1/rankings

Query Parameters

이름타입필수설명
periodstring필수day · week · month · year
categorystring선택카테고리 ID. 미입력 시 전체
datestring선택YYYY-MM-DD 기준일. 미입력 시 최신
limitnumber선택반환 순위 수. 기본 50, 최대 200
 
{

    { "rank": 2, "isbn13": "9788960770331", "title": "...", "author": "..." }
  ]
}

신간 / 스테디 셀러

신간 도서(최근 N일 출간) 및 스테디 셀러(장기 베스트) 집계를 조회합니다.

GET /v1/rankings/new-releases
GET /v1/rankings/steady-sellers

저자 프로필

저자 ID로 프로필 정보와 출간 도서 목록을 조회합니다.

GET /v1/authors/{id}
GET /v1/authors/{id}/books

리뷰 / 평점

특정 상품의 평균 평점, 별점 분포, 리뷰 요약 등을 제공합니다. 개별 회원 리뷰 텍스트는 동의 회원의 것만 노출됩니다.

GET /v1/products/{id}/reviews
이름타입필수설명
summaryboolean선택AI 리뷰 요약 포함 여부. 기본 false
pagenumber선택페이지 번호

제휴 링크 생성 (애드온)

PARTNER 애드온 연동 신청자만 사용할 수 있는 API입니다. 추천 결과의 상품 링크에 자동으로 제휴 파라미터를 부착해 줍니다.

POST /v1/addon/affiliate-links 
curl -X POST "https://api.yes24.com/v1/addon/affiliate-links" \
  -H "Authorization: Bearer yes24_live_xxxxxxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "isbn13s": ["9788960778795", "9791162241813"],
    "placement": "recommend_card"
  }'

# 응답
{
  "links": [
    {
      "isbn13": "9788960778795",
      "url": "https://www.yes24.com/Product/Goods/76661016?affId=YR-XXXX"
    }
  ]
}
