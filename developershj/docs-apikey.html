API Key 발급

YES24 Open API는 발급받은 API Key를 요청 헤더에 넣어 사용하는 방식입니다. 신청 정보를 입력하면 즉시 Key가 발급됩니다.

사전 요건

  • 담당자 이름과 이메일을 준비합니다.
  • 서비스명, 서비스 URL, 서비스 설명, API 사용 목적, YES24 아이디는 선택 입력입니다.
  • 발급받은 API Key로 Category API와 Goods API를 호출할 수 있습니다.

발급 절차

  1. 1
    API Key 신청 페이지 접속

    API Key 신청 페이지로 이동합니다.

  2. 2
    담당자 정보 입력

    담당자명과 이메일을 입력합니다. API 사용 목적은 필요 시 함께 작성할 수 있습니다.

  3. 3
    서비스 정보와 YES24 계정 정보 입력

    서비스명, 서비스 URL, 서비스 설명, YES24 아이디는 선택 항목입니다. 입력하지 않아도 API Key 발급을 진행할 수 있습니다.

  4. 4
    약관 동의 후 즉시 발급

    필수 약관에 동의하고 API Key 즉시 발급받기를 누르면 Key가 화면에 표시됩니다.

    ⚠️

    API Key는 최초 발급 시에만 원문이 표시됩니다. 반드시 복사하여 안전한 곳에 보관하세요.

  5. 5
    JSON 저장 정보 확인

    발급 결과 화면에서 API Key와 함께 저장된 신청 JSON을 확인합니다.

  6. 6
    첫 API 호출

    발급받은 API Key를 X-API-Key 헤더에 포함하여 API를 호출합니다.

    Shell 
    curl -X GET "https://api.yes24.com/v1/goods/itemList?query=파이썬" \
  -H "X-API-Key: yk_live_YOUR_API_KEY"
🔒
보안 주의

API Key는 외부에 노출되지 않도록 관리하고, 클라이언트 사이드 코드에 직접 포함하지 않는 것을 권장합니다.
