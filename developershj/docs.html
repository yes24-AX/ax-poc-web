YES24 Open API 개요

YES24 Open API를 사용하여 도서, 상품, 검색 데이터를 애플리케이션에 통합하세요.

최종 업데이트: 2026년 6월

YES24 Open API란?

YES24 Open API는 외부 개발자가 YES24의 도서, 상품, 검색 데이터를 활용하여 서비스를 구축할 수 있도록 제공하는 공식 API입니다.

REST 방식으로 설계되었으며, JSON 형식으로 응답합니다. OAuth 2.0 기반의 인증을 사용합니다.

ℹ️

현재 버전: v1.0 (오픈 베타)

Open Beta 기간 중입니다. API 스펙은 변경될 수 있으며, 변경 사항은 공지사항을 통해 사전 안내됩니다.

제공 API

API설명Endpoint
Books API도서 검색, 상세 정보, 미리보기/v1/books
Products API상품 조회, 가격, 재고/v1/products
Search API통합 검색, 자동완성, 연관 검색어/v1/search
Common Codes API카테고리, 출판사, 공통 코드 조회/v1/codes

Base URL

모든 API 요청은 아래 Base URL을 사용합니다.

https://api.yes24.com /v1

인증

YES24 Open API는 OAuth 2.0 Client Credentials 방식을 사용합니다. 모든 API 요청에는 Access Token이 필요합니다.

  1. My Applications에서 앱을 생성하여 Client ID와 Client Secret을 발급받습니다.
  2. Token Endpoint에 요청하여 Access Token을 발급받습니다.
  3. API 요청 헤더에 Authorization: Bearer {token}을 포함합니다.

Rate Limit

플랜분당 요청일일 요청
Free100회10,000회
Standard500회100,000회
Enterprise협의협의

Rate Limit 초과 시 HTTP 429 Too Many Requests가 반환됩니다. 응답 헤더의 X-RateLimit-Reset에서 초기화 시각을 확인할 수 있습니다.

응답 형식

모든 응답은 Content-Type: application/json으로 반환됩니다.

json — 성공 응답 
{
  "success": true,
  "data": { ... },
  "meta": {
    "total": 120,
    "page": 1,
    "size": 20
  }
}
json — 오류 응답 
{
  "success": false,
  "error": {
    "code": "AUTH_001",
    "message": "Invalid or expired access token.",
    "docs": "https://developers.yes24.com/support#error-codes"
  }
}

SDK 및 라이브러리

공식 SDK는 현재 준비 중입니다. REST API를 직접 호출하거나 API Explorer에서 테스트할 수 있습니다.

⚠️

공식 SDK가 출시되기 전까지는 직접 HTTP 요청을 사용하세요. 서드파티 라이브러리 사용 시 YES24는 지원을 보장하지 않습니다.
