YES24 Open API 개요

YES24 Open API를 사용하여 카테고리와 상품 데이터를 애플리케이션에 통합하세요.

최종 업데이트: 2026년 6월

YES24 Open API란?

YES24 Open API는 외부 개발자가 YES24의 카테고리, 베스트셀러, 신상품, 상품 정보를 활용하여 서비스를 구축할 수 있도록 제공하는 공식 API입니다.

REST 방식으로 설계되었으며, JSON 형식으로 응답합니다. 발급받은 API Key를 요청 헤더에 포함하는 방식으로 인증합니다.

ℹ️

현재 버전: v1.0 (오픈 베타)

Open Beta 기간 중입니다. API 스펙은 변경될 수 있으며, 변경 사항은 공지사항을 통해 사전 안내됩니다.

제공 API

API설명Endpoint
Category API카테고리 목록, 베스트셀러, 신상품 조회/v1/category
Goods API상품 검색, 상품 상세, 목차, 작가 정보 조회/v1/goods

Base URL

모든 API 요청은 아래 Base URL을 사용합니다.

https://api.yes24.com /v1

Rate Limit

구분일일 요청비고
기본 정책5,000회 이하API Key 기준

Rate Limit은 API Key 기준 일 요청 5,000회 이하로 적용됩니다.

Rate Limit 초과 시 HTTP 429 Too Many Requests가 반환됩니다. 응답 헤더의 X-RateLimit-Reset에서 초기화 시각을 확인할 수 있습니다.

응답 형식

모든 응답은 Content-Type: application/json으로 반환됩니다.

json — 성공 응답 
{
  "success": true,
  "message": "성공",
  "data": { ... },
  "errorCode": null
}
json — 오류 응답 
{
  "success": false,
  "error": {
    "code": "AUTH_001",
    "message": "API Key가 없거나 유효하지 않습니다.",
    "docs": "https://developers.yes24.com/support#error-codes"
  }
}

페이징 정책

목록형 API는 page와 pageSize Query Parameter를 사용해 결과 범위를 지정합니다.

파라미터기본값설명
page1조회할 페이지 번호
pageSize20페이지당 결과 수, 최대 100

응답에는 현재 페이지, 페이지 크기, 전체 데이터 수가 함께 반환됩니다.

json — 페이징 응답 예시 
{
  "data": {
    "items": [ ... ],
    "currentPage": 1,
    "pageSize": 20,
    "totalCount": 100
  }
}

SDK 및 라이브러리

공식 SDK는 현재 준비 중입니다. REST API를 직접 호출하거나 API 테스트에서 테스트할 수 있습니다.

⚠️

공식 SDK가 출시되기 전까지는 직접 HTTP 요청을 사용하세요. 서드파티 라이브러리 사용 시 YES24는 지원을 보장하지 않습니다.
