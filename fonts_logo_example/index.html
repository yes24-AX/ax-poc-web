폰트 라이선스 확인

확인 결과, 아래 5개 폰트 모두 회사 웹사이트·상업 서비스에 무료로 사용할 수 있습니다.

폰트 상업적 웹 사용 확인한 조건
Poppins 가능 SIL OFL 1.1. 상업 이용·웹 임베딩 가능. 단, 한글 글리프는 없음 — 영문 타이틀 전용으로 써야 합니다.
ONE Mobile Title 가능 개인·기업 모두 무료, 웹사이트·BI/CI·임베딩 가능. 다만 폰트 파일 자체의 판매·수정·재배포는 금지.
경기천년제목 가능 웹·인쇄·영상 등 자유 사용 가능. 폰트 파일을 유료 양도·판매하는 행위만 금지.
IBM Plex Sans KR 가능 SIL OFL 1.1. 상업 이용·웹/앱 임베딩 가능. 수정본을 배포할 경우 폰트명 관련 OFL 조건을 따라야 함.
여기어때 잘난체 (YG Jalnan) 가능 웹사이트·광고·BI/CI 등 상업 사용 가능. 폰트 파일 자체 판매·임의 수정 후 재배포는 금지. BI/CI에 사용해도 상표 등록은 불가.
