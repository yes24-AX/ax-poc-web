# 디자이너 평가 — AX Datahub 온보딩 티저 5안

평가자 역할: 시니어 프로덕트/모션 디자이너
평가 기준: 비주얼 완성도 · 모션 설계 · 레퍼런스 소화력 · 독창성·기억성 (각 10점, 안당 40점 만점)

## 검증 방법

5안 모두 헤드리스 Chrome 으로 직접 캡처해 확인했습니다. 총 40여 장 — 데스크톱 1440×900 각 안 5장 이상 + 모바일 500폭.

- t5 는 `#step=` 캡처가 GSAP 타임라인 중간(마스크 `inset(48% 0 48% 0)`)에 멈춰 화면 중앙에 밴드 아티팩트가 나왔습니다. 소스에 있는 `?seek=` 훅으로 정착 프레임(2.6 / 5.4 / 9.6 / 16.4 / 19.6 / 22.6초)을 다시 받아 재평가했고, 밴드는 감점하지 않았습니다.
- t2 카드가 오른쪽으로 잘려 보이는 것도 `cardin` 애니메이션 미완(`translateX(26px)` 초기 상태) 아티팩트라 감점하지 않았습니다. 다만 가상시간 예산을 30초로 늘려 재캡처했을 때도 동일하게 나온 구도 문제(피날레 카메라)는 실제 결함으로 판정했습니다.
- 타이포·컬러·레이아웃 수치는 각 안의 CSS 를 직접 읽어 확인했습니다.

## 안별 총평

### t1 — 유체 수렴 (35점) / 참고: Lusion, Immersive Garden

픽셀 크래프트가 이 판에서 제일 높습니다. SDF 레이마칭에 ACES 톤매핑, IOR 을 0.982 / 1.0 / 1.018 로 세 번 굴절시킨 색분산, 볼류메트릭 헤일로까지 실제로 구현했습니다.

모션이 장식이 아닌 게 결정적입니다. `yawAt()` 이 카메라 요를 단일 소스로 관리하면서 흩어진 동안은 느리게 흐르다 병합 구간(8.2~16.0s)에서 한 번 크게 돌고 17.3s 에 얼어붙습니다. 블렌드 반경 K 를 0.34 → 0.58 → 0.42 로 애니메이트해 여섯 색이 회색으로 평균화되지 않게 막은 것도 의도적입니다(소스 주석에 그 이유가 적혀 있습니다). 02 '지연' 비트에서는 도메인마다 0.5초 간격으로 순차 발광시켜 "여섯 번 따로 물어야 했다"를 움직임으로 말합니다.

약점: 스틸로 보면 01 과 02 가 거의 같은 그림입니다(02 의 순차 발광은 지나가면 사라짐). 04 메트릭의 취소선 "6곳"·"32분" 이 0.55em 에 알파 0.30 이라 사실상 안 보이는데, 전후 대비가 그 장면의 논지 전부입니다.

### t4 — 계기판 조판 (31점) / 참고: Obys Agency, ERA

타이포 시스템이 가장 통제돼 있습니다. 슬레이트 프레임·코너 크롭마크·10~11px/.2em 이상 모노 마이크로레이블이 전 장면에서 어긋나지 않고, 02 에서 다크 → 페이퍼로 반전해도 시스템이 안 깨집니다.

진짜 강점은 정보 설계입니다. 02 에서 "214분"을 크게 던지고 끝내는 게 아니라, 오른쪽에 리더닷 원장(시스템 접속 12분 + 로그인·권한 확인 18분 + 엑셀 내려받기·병합 96분 + 기준 불일치 재확인 64분 + 담당자 회신 대기 24분 = 합계 214분)을 놓아 숫자를 **벌어냅니다**. Obys 를 베낀 사람은 많아도 이걸 하는 사람은 드뭅니다.

약점: 모션이 가장 적습니다. 장면이 서로를 대체할 뿐 전환이 의미를 만들지 않습니다. 04 조인 테이블의 올리브-라임 하이라이트는 색도 탁하고 x=330 에서 하드하게 잘려 미완성 셀렉션처럼 보입니다. 전 장면 상·하단에 200px 안팎의 빈 띠가 있는데, Obys 는 여백을 쓰되 가장자리를 데이터로 채웁니다.

### t3 — 키네틱 타이포 (30점) / 참고: Cuberto, Dogstudio

컬러 상단 엣지 + 스파크라인을 가진 여섯 다크 카드는 이 판에서 가장 잘 만든 UI 오브젝트고, 03 의 다크 ↔ 크림 반전은 진짜 구도적 사건입니다. 02 의 "6곳을 열어야 / 1개를 압니다" 취소선은 장식이 아니라 문장 자체라 편집적으로 옳습니다.

치명적인 건 `.giant{line-height:.94}` 입니다. 최대 150px 에서 02 의 "열어야" 받침이 "1개를" 상단과 물리적으로 충돌합니다. 라틴 디스플레이 세팅을 한글에 검증 없이 적용한 것으로, 이 굵기라면 1.02~1.06 이 하한입니다.

그 외: 900px 높이 전 프레임 하단에 no-JS 폴백 콘텐츠가 새어나옵니다(`body.js #app{position:fixed}` 가 아래 흐름 콘텐츠를 못 가림 — 30초 예산 재캡처에서도 동일). 00 의 "6곳"(44px 오렌지 숫자 + 14px 단위)은 큰 여백에 앵커 없이 떠 있습니다. 05 피날레 3×2 카드 그리드는 깔끔하지만 다섯 안의 마무리 중 가장 평범합니다.

### t5 — 질문의 연속 (27점) / 참고: ERA Residence, Active Theory

정착 프레임 한 장씩만 보면 가장 아름답습니다. 03(눈 덮인 숲 + 앰버 틴트 + 86px weight 200 "무엇이 모자라나" + 헤어라인 룰 + 하단 메타 행)은 이 판 전체에서 가장 시네마틱하게 조판된 이미지입니다. CSS 주석에 선언한 규칙 — 사진은 전부 그레이스케일, 색은 오직 데이터 신호로만 `mix-blend-mode:color` 9% — 을 끝까지 지킨 것도 진짜 규율입니다.

모션도 잘 짜여 있습니다. 하드컷 색면 플래시(0.07초 인 / 0.42초 아웃), 가로 밴드 마스크 리빌, 4% 오버스캔 안에서만 흐르는 사진(확대 없음). 이전 장면을 다음 장면의 마스크가 다 열린 뒤에 치워서 리빌이 검은 띠가 아니라 이전 화면 위를 덮으며 열리게 한 것도 계산된 처리입니다.

문제는 레퍼런스 소화입니다. ERA Residence 에서 사진이 작동하는 이유는 **사진이 곧 상품**(건물·빛·재질)이기 때문인데, 사내 데이터 포털로 옮겨오니 사진이 가리킬 대상이 없어 무관한 스톡 6장이 됐습니다. 재고 = 눈 덮인 숲, 이벤트 = 폐허 벽돌방, 고객 행동 = 은하수. 07 수렴 장면에서 여섯 장이 3×2 로 나란히 서는 순간 이 자의성이 한눈에 드러납니다. 도메인당 2.25초 × 6 이 균등해 중간부에 형태가 없는 것도 감점 요인입니다.

### t2 — 데이터 월드 (22점) / 참고: Bruno Simon, Active Theory

타이포가 압도적으로 약합니다. 내레이션이 하단 20px 볼드 한 줄뿐 — 아이브로도 스케일 대비도 없는 게임 자막이고, 일부 프레임에선 옅은 하늘 위에 회색으로 얹혀 대비가 무너집니다. 파스텔 팔레트는 채도가 낮아 전반적으로 바래 보이고, 우상단 HUD 는 폭이 제각각인 필 3개 스택이라 디버그 UI 처럼 읽힙니다.

더 근본적으로는 레퍼런스를 표면만 가져왔습니다. Bruno Simon 사이트가 성립하는 건 **운전하는 행위 자체가 포트폴리오**여서인데, 여기선 공을 굴려 육각 섬에 닿는 것이 여섯 데이터를 질의하는 일과 아무 관계가 없습니다. 정작 제품 논지는 3D 위에 얹은 2D 카드가 전달합니다. 장난감만 빌리고 이유는 두고 왔습니다.

피날레(step 6)는 가상시간 예산 30초로 재캡처해도 동일합니다 — 여섯 입구 중 "고객 행동" 하나만 보이고, 화면 중앙-좌측 전체가 빈 하늘이며, 섬들은 우하단에서 잘려나가고, 중앙에 정체 불명의 흰 플랫폼이 떠 있습니다. 사용자가 문을 고르는 가장 중요한 화면인데 구도가 없습니다.

## 가장 강한 단일 장면 (5안 통틀어 1개)

**t1 step 04 — 수은 허브.**

어두운 유리 코어 위에 "여섯 개의 입구, 하나의 흐름"이 직접 얹히고, 여섯 갈래 액체 스포크가 각 색 노드로 뻗습니다.

고른 이유는 예뻐서가 아니라 **형태와 주장이 같은 사물**이기 때문입니다. 하나인데 여섯으로 되어 있다는 걸 캡션 없이 눈으로 보여주고, 그 자체가 그대로 내비게이션입니다. 유리·색분산·볼류메트릭 라이팅의 렌더 수준도 나머지 넷이 도달하지 못한 지점입니다. 모바일 500폭에서도 허브가 위, 2×3 카드가 아래로 무너지며 그대로 성립합니다.

차점은 t4 step 05 입니다. 02 에서 던진 질문을 캐럿 깜빡이며 다시 묻고, 2×2 교차 도메인 응답 격자를 놓고, "이전 214분" 취소선 위에 라임 "8.0초"를 얹은 뒤, 하단 룰에 "판단 — 재고 3종 즉시 보충 · 기획전 1주 연장"을 놓습니다. **지표가 아니라 결정을 보여준 유일한 프레임**입니다. 이미지로서의 힘은 t1 이, 논지로서의 힘은 t4 가 앞섭니다.

## 내 순위와 이유

**t1 › t4 › t3 › t5 › t2**

- **t1** — 크래프트와 개념이 같은 지점에서 만나는 유일한 안입니다. 레퍼런스를 형태가 아니라 방법(레이마칭·물리 기반 라이팅)으로 소화했고, 그 방법으로 두 레퍼런스에도 없는 형태에 도달했습니다.
- **t4** — 논지가 가장 단단하고 시스템 완성도도 높지만, 모션 저작이 거의 없어 '티저'보다 '조판'에 가깝습니다. 반대로 말하면 인쇄물로 옮겨도 살아남는 유일한 안입니다.
- **t3** — 아이디어(여섯 카드가 한 덱으로 접히되 옆면에서 여섯 색을 여전히 셀 수 있음)가 좋은데 마감이 아쉽습니다. 행간과 폴백 누출만 고치면 t4 와 자리를 바꿀 여지가 있습니다.
- **t5** — 프레임 미학은 순위보다 높지만 사진이 제품과 무관해 5초 뒤 남는 게 무드뿐입니다. 이미지 교체만으로 상위권 진입이 가능한, 잠재력 대비 손해를 본 안입니다.
- **t2** — 타이포와 구도 양쪽에서 프로 기준에 못 미칩니다. 3D 자산 제작량은 가장 많은데 그 노력이 제품 메시지로 환산되지 않습니다.

## 채택 시 반드시 고쳐야 할 것 (안당 1가지)

- **t1** — **최종 화면 서브카피 가독성.** `.final .head{width:min(92vw,520px)}` 인데 다크 코어 폭은 약 330px 이라, 14px / 알파 0.56 짜리 한 줄이 구조적으로 코어를 벗어나 밝은 스포크 위에 걸칩니다. 헤드 블록을 코어 폭에 맞추거나 서브 전용 백플레이트를 주세요. (부차: 04 취소선 수치를 0.55em / 알파 0.30 에서 끌어올릴 것 — 전후 대비가 그 장면의 논지입니다.)
- **t2** — **피날레 카메라.** 여섯 입구 중 하나만 보이고 중앙-좌측이 통째로 비는 현재 구도로는 결정 화면이 성립하지 않습니다. 피날레만이라도 카메라를 고정 컴포지션으로 락하고 여섯 입구가 모두 프레임 안에 들어오게 하세요.
- **t3** — **`.giant` 의 `line-height:.94` 를 1.02~1.06 으로.** 현재 한글 받침과 다음 줄 상단이 물리적으로 충돌합니다. 겸사겸사 하단으로 새는 no-JS 폴백 슬리버도 막아주세요.
- **t4** — **04 조인 테이블의 올리브-라임 하이라이트.** 색 자체가 근-블랙 위에서 탁하고 하드 엣지가 미완성 셀렉션처럼 보입니다. 05 에서 라임이 '이후' 신호로 잘 작동하니, 04 의 조인 키는 채움 대신 얇은 좌우 룰이나 저채도 처리로 바꾸고 라임은 05 전용으로 아껴두세요.
- **t5** — **사진 여섯 장 교체.** 도메인과 실제로 연결되는 이미지로 갈아끼우거나(사내 물류·매대·CS 데스크 등 실사), 아니면 사진을 버리고 그 자리를 데이터 텍스처로 채우세요. 07 수렴 프레임이 이 문제를 그대로 폭로하기 때문에, 이것만 해결되면 t5 는 상위권으로 올라갑니다.
