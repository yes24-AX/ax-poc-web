# DataHub Interactive Onboarding — Find the Answer

사내 직원이 회원, 주문, 상품, 매출, GA4 등 흩어진 데이터를 연결해 더 나은 의사결정의 근거를 발견하는 인터랙티브 온보딩입니다.

## Story

사용자는 `이번 달 매출은 왜 달라졌을까?`라는 질문으로 시작합니다. 사내 DB와 GA4에서 근거를 모으고, 데이터의 의미를 정리하고, Column Key를 직접 바인딩하고, 인증된 데이터를 선택합니다. 연결된 데이터는 하나의 패턴을 보여주며 마지막에는 전체 과정이 DataHub Interface로 변형됩니다.

## Journey

1. Question — 매출 변화에 대한 질문을 활성화합니다.
2. Sources — 회원 DB, 주문 DB, GA4를 질문에 추가합니다.
3. Meaning — 값들을 회원, 주문, 유입, 매출의 의미로 정렬합니다.
4. Connect — 빛나는 데이터 카드를 `상품 → 회원 → 주문 → 매출 → GA4` 순서로 선택합니다. 기술적인 연결은 DataHub가 자동으로 처리합니다.
5. Standard — 개인 추출 파일과 회사 공식 매출 지표를 비교해 보고와 의사결정에 사용할 기준을 선택합니다.
6. Pattern — 연결된 데이터에서 유입 증가, 전환 감소, 상품 가용성 저하를 발견합니다.
7. Company — 하나의 분석 뒤에 회사 전체 데이터가 연결되어 있음을 확인합니다.
8. DataHub — Insight를 Interface에 배치해 답을 완성합니다.

## Business-friendly connection

일반 사업부 사용자가 테이블명이나 Column Key를 몰라도 이해할 수 있도록 데이터의 역할을 업무 언어로 표현합니다.

- GA4 — 고객이 어디에서 방문했는가
- 회원 — 누가 방문했는가
- 주문 — 무엇을 구매했는가
- 상품 — 어떤 상품이 움직였는가
- 매출 — 결과가 어떻게 변했는가

모든 단계는 오른쪽 상단 가이드의 `SKIP THIS STEP`으로 건너뛸 수 있습니다. Skip을 눌러도 해당 단계의 수집, 연결, 선택, 분석 애니메이션을 실제로 재생한 후 다음 단계가 열립니다.
