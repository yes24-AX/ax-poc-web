약관 동의

YES24 Open API 이용약관 (요약)

1. 발급된 API Key는 신청자 본인 또는 신청 시 기재한 서비스에 한해 사용되어야 합니다.

2. API 응답 데이터는 출처 표기와 함께 사용해야 하며, 데이터 자체를 재판매하거나 대량 추출·복제하여 별도 서비스를 구축할 수 없습니다.

3. 분당 또는 일일 호출 한도를 초과하는 비정상 호출이 감지될 경우 사전 통보 없이 키 사용이 중단될 수 있습니다.

4. YES24는 비상업적 사용을 우선으로 하며, 상업적 사용은 적정 한도 내에서 허용됩니다.

5. 본 약관의 자세한 내용은 이용약관 전문을 참고해 주세요.
